# Impronta Estampa

Landing page de Impronta Estampa (San Juan, Argentina) con diseñador 3D de prendas.

- Sitio en vivo: https://improntaestampa.pages.dev
- `src/` es el código fuente (HTML, CSS, JS, three.js). Editá acá.
- `assets/` tiene las fotos de la galería.
- `site/` es la versión construida que se publica. No la edites a mano: corré `node build.js`, que genera `site/` desde `src/`.
- `deploy/deploy.sh` publica en Cloudflare (Pages + Worker). Necesita `CLOUDFLARE_API_TOKEN` y `CLOUDFLARE_ACCOUNT_ID` en el entorno. Nunca subas el token al repo.
